### 表结构对应（MySQL `online_teach`）

| 表 | 关键字段 | 关系 |
|---|---|---|
| users | id, username(唯一), email, password, is_teacher, avatar, bio, is_staff | 1-N 授课课程；M-N 选课；1-N 提交 |
| courses | id, name, code(唯一), description, teacher_id, created_at, updated_at | N-1 教师；M-N 学生；1-N 作业 |
| assignments | id, course_id, title, description, deadline, reference_file, created_at | N-1 课程；1-N 提交 |
| submissions | id, assignment_id, student_id, code, status, score, output, created_at | N-1 作业；N-1 学生 |

## 2. 后端设计类图（Django/DRF 分层）

```mermaid
classDiagram
    class UserViewSet {
        +get_permissions() 注册匿名,其余登录
        +perform_create() 保存用户并发送注册邮件
        +me() 返回当前用户
    }
    class CourseViewSet {
        +get_queryset() 按角色过滤
        +create() 教师创建
        +perform_create() 自动设置 teacher
        +enroll() 学生选课
        +unenroll() 学生退课
    }
    class AssignmentViewSet {
        +get_queryset() 按课程过滤
    }
    class SubmissionViewSet {
        +get_queryset() 学生看自己/教师看本课程
        +create() 校验教师/选课/截止时间
        +grade() 教师评分(0-100)
    }
    class IsCourseTeacherOrReadOnly {
        +has_permission() 教师可写
        +has_object_permission() 授课教师/管理员可改
    }
    class UserSerializer {
        +password 只写
        +email 必填
        +create() 密码哈希
    }
    class CourseSerializer {
        +teacher_name 只读
        +student_count 计算
        +students 按角色返回
        +is_enrolled 计算
    }
    class AssignmentSerializer {
        +reference_file_url 计算
    }
    class SubmissionSerializer {
        +student_name 只读
        +assignment_title 只读
        +student/assignment 只读(防篡改)
    }
    class User
    class Course
    class Assignment
    class Submission

    UserViewSet --> UserSerializer
    CourseViewSet --> CourseSerializer
    AssignmentViewSet --> AssignmentSerializer
    SubmissionViewSet --> SubmissionSerializer
    CourseViewSet --> IsCourseTeacherOrReadOnly
    AssignmentViewSet --> IsCourseTeacherOrReadOnly
    UserSerializer --> User
    CourseSerializer --> Course
    AssignmentSerializer --> Assignment
    SubmissionSerializer --> Submission
    UserViewSet --> User
    CourseViewSet --> Course
    AssignmentViewSet --> Assignment
    SubmissionViewSet --> Submission
```

### 关键设计说明

1. **权限分层**：`IsCourseTeacherOrReadOnly` 同时挂在课程与作业 ViewSet 上；`has_permission` 控制"创建"，`has_object_permission` 控制"修改/删除"，通过 `obj.course.teacher` 兼容两类对象（今日修复）。
2. **提交创建**：`SubmissionViewSet.create` 不走序列化器默认流程，显式校验"非教师 + 已选课 + 未过期"后创建 `pending` 记录（今日修复）。
3. **字段防篡改**：`SubmissionSerializer` 将 `student`/`assignment` 设为只读，防止 PATCH 挪动提交归属（今日修复）。
4. **注册邮件**：`UserSerializer.create` 负责密码哈希；`UserViewSet.perform_create` 在保存成功后发送通知邮件，失败仅记日志。
5. **参考文档**：`Assignment.reference_file` 为 FileField，序列化时提供 `reference_file_url` 供前端下载。
