# 对象级顺序图（详细设计说明书）

- **版本**：v1.0　**日期**：2026-08-29
- **范围**：用例清单 UC01~UC14 各 1 张，编号 OBJ-SEQ01 ~ OBJ-SEQ14
- **说明**：在组件级顺序图（COMP-SEQ）基础上展开到类与关键方法，对应 `views.py`、`serializers.py`、`permissions.py`、`models.py`。

## UC01 用户注册（OBJ-SEQ01）

```mermaid
sequenceDiagram
    actor U as 用户
    participant Page as Register.jsx
    participant Send as SendVerificationCodeView.post
    participant Code as EmailVerificationCode.issue
    participant Mail as send_mail
    participant VS as UserViewSet.create
    participant Ser as UserSerializer.validate/create
    participant User as User.set_password
    participant DB as MySQL

    U->>Page: 获取验证码
    Page->>Send: POST /api/auth/send-code/
    Send->>Code: issue(email)
    Code->>DB: INSERT email_verification_codes
    Send->>Mail: 发送 6 位码
    U->>Page: 提交注册
    Page->>VS: POST /api/users/ + verification_code
    VS->>Ser: is_valid()
    Ser->>Code: 校验并 consume
    Ser->>User: set_password 后 create
    User->>DB: INSERT users
    VS-->>Page: 201
```

## UC06 教师编辑 / 删除课程（OBJ-SEQ06）

```mermaid
sequenceDiagram
    actor T as 教师
    participant Page as CourseList.jsx
    participant VS as CourseViewSet.update / destroy
    participant Perm as IsCourseTeacherOrReadOnly.has_object_permission
    participant Course as Course
    participant DB as MySQL

    T->>Page: 保存或删除
    Page->>VS: PATCH / DELETE
    VS->>Perm: obj.teacher 或管理员
    alt 否
        VS-->>Page: 403/404
    else 是
        VS->>Course: save / delete（级联）
        Course->>DB: UPDATE / DELETE
        VS-->>Page: 200/204
    end
```
