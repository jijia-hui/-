- **版本**：v1.1　**日期**：2026-08-26（v1.1：UC14 自动评测删除，UC15 顺延为 UC14，编号 SYS-SEQ01 ~ SYS-SEQ14）
- **范围**：用例清单（`业务场景用例清单_v1.md`）中每个用例 1 张系统级顺序图，对应编号 SYS-SEQ01 ~ SYS-SEQ14
- **图例**：参与者（Actor）为角色；「前端页面」「后端 API」「MySQL」为系统内部子系统（系统边界内）；「邮件系统」为外部系统

## UC01 用户注册（SYS-SEQ01）

```mermaid
sequenceDiagram
    actor U as 用户
    participant FE as 前端页面
    participant API as 后端 API
    participant DB as MySQL
    participant MAIL as 邮件系统

    U->>FE: 填写用户名/邮箱/密码，选择身份，提交
    FE->>API: POST /api/users/ {username,email,password,is_teacher}
    API->>DB: 校验用户名唯一性，创建用户（密码哈希）
    DB-->>API: 用户记录
    API->>MAIL: 发送"注册成功"通知邮件（失败仅记日志）
    API-->>FE: 201 注册成功
    FE-->>U: 提示注册成功，跳转登录页
    Note over U,MAIL: 备选：用户名已存在/邮箱格式错误 → 400 提示失败<br/>邮件发送失败 → 注册仍成功
```

## UC02 用户登录（SYS-SEQ02）

```mermaid
sequenceDiagram
    actor U as 用户
    participant FE as 前端页面
    participant API as 后端 API
    participant DB as MySQL

    U->>FE: 输入用户名/密码，提交
    FE->>API: POST /api/auth/token/
    API->>DB: 校验用户名与密码
    DB-->>API: 校验结果
    API-->>FE: 200 + Token（失败 → 400"用户名或密码错误"）
    FE->>API: GET /api/users/me/（携带 Token）
    API-->>FE: 用户信息（用户名/邮箱/身份）
    FE->>FE: 保存 Token 与用户信息，进入课程页
```

## UC03 浏览课程列表与课程详情（SYS-SEQ03）

```mermaid
sequenceDiagram
    actor U as 用户
    participant FE as 前端页面
    participant API as 后端 API
    participant DB as MySQL

    U->>FE: 进入"我的课程"页
    FE->>API: GET /api/courses/
    API->>DB: 查询全部课程（含学生数、当前用户选课状态）
    DB-->>API: 课程列表
    API-->>FE: 200 课程列表
    FE-->>U: 渲染课程卡片（编号/教师/学生数/选课标记）
    U->>FE: 点击课程卡片
    FE->>API: GET /api/courses/{id}/
    API->>DB: 查询课程详情与学生列表
    DB-->>API: 课程详情
    API-->>FE: 200 课程详情
    FE-->>U: 展示作业列表与学生列表（无权限时学生列表为空）
```

## UC04 学生选课 / 退课（SYS-SEQ04）

```mermaid
sequenceDiagram
    actor S as 学生
    participant FE as 前端页面
    participant API as 后端 API
    participant DB as MySQL

    S->>FE: 点击课程卡片"选课"按钮
    FE->>API: POST /api/courses/{id}/enroll/

    DB-->>API: 成功

    FE->>API: GET /api/courses/（刷新）

```

## UC05 教师创建课程（SYS-SEQ05）

```mermaid
sequenceDiagram
    actor T as 教师
    participant FE as 前端页面
    participant API as 后端 API
    participant DB as MySQL

    T->>FE: 点击"创建课程"，填写名称/编号/描述

    Note over T,DB: 备选：编号重复 → 400；学生调用 → 403
```

## UC06 教师编辑 / 删除课程（SYS-SEQ06）

```mermaid
sequenceDiagram
    actor T as 教师
    participant API as 后端 API
    participant PERM as 权限校验
    participant DB as MySQL

    T->>API: PATCH/DELETE /api/courses/{id}/
    API->>PERM: 校验是否为该课程授课教师（或管理员）
    alt 非授课教师
        PERM-->>API: 拒绝
        API-->>T: 403/404
    else 授课教师
        API->>DB: 更新或删除课程（删除级联作业与提交）
        DB-->>API: 成功
        API-->>T: 200/204
    end
```

## UC07 教师管理作业（创建 / 编辑 / 删除，含参考文档）（SYS-SEQ07）

```mermaid
sequenceDiagram
    actor T as 教师
    participant FE as 前端页面
    participant API as 后端 API
    participant FS as 媒体存储
    participant DB as MySQL

    T->>FE: 填写标题/描述/截止时间，可选上传参考文档

    FE-->>T: 提示成功，刷新列表
    Note over T,DB: 删除：DELETE /api/assignments/{id}（Popconfirm 确认）<br/>备选：非授课教师 → 403；学生 → 403
```

## UC09 学生提交作业（SYS-SEQ09）

```mermaid
sequenceDiagram
    actor S as 学生
    participant FE as 前端页面
    participant API as 后端 API
    participant DB as MySQL

    S->>FE: 选择文本文件（.py/.txt/.md 等）
    FE->>FE: FileReader 读取文件内容
    S->>FE: 点击"提交作业"
    FE->>API: POST /api/submissions/ {assignment, code}
    API->>API: 校验：非教师、已选课、未过截止时间
    alt 校验失败
        API-->>FE: 403/400（教师/未选课/已截止）
        FE-->>S: 显示具体错误提示
    else 校验通过
        API->>DB: 创建提交记录（status=pending, score=0）
        DB-->>API: 提交记录
        API-->>FE: 201 提交成功
        FE-->>S: 提示"提交成功"，刷新提交记录
    end
```

## UC12 教师评分（SYS-SEQ12）

```mermaid
sequenceDiagram
    actor T as 教师
    participant FE as 前端页面
    participant API as 后端 API
    participant PERM as 权限校验
    participant DB as MySQL

    T->>FE: 在评分弹窗输入 0-100 分，点击保存
    FE->>API: POST /api/submissions/{id}/grade/ {score}
    API->>PERM: 校验教师身份且为该课程授课教师
    alt 无权限
        PERM-->>API: 拒绝
        API-->>FE: 403"你无权评分此提交"
    else 有权限
        API->>API: 校验分数为 0-100 整数（否则 400）
        API->>DB: 更新 score，status=graded
        DB-->>API: 成功
        API-->>FE: 200 已评分提交
        FE->>API: GET /api/submissions/?assignment={id}（刷新）
        API-->>FE: 更新后的列表
        FE-->>T: 提示"评分已保存"
    end
```

## UC14 管理员后台管理（SYS-SEQ14）

```mermaid
sequenceDiagram
    actor A as 管理员
    participant ADM as Django Admin
    participant ORM as ORM(模型)
    participant DB as MySQL

    A->>ADM: 登录 /admin/
    ADM->>DB: 校验管理员身份
    DB-->>ADM: 通过
    A->>ADM: 管理用户/课程/作业/提交（增删改查、筛选）
    ADM->>ORM: 调用模型管理接口
    ORM->>DB: SQL 读写
    DB-->>ORM: 结果
    ADM-->>A: 列表/表单页面更新
```
