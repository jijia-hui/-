# 组件级顺序图（概要设计说明书）

- **版本**：v1.0　**日期**：2026-08-29
- **范围**：用例清单 UC01~UC14 各 1 张，编号 COMP-SEQ01 ~ COMP-SEQ14
- **说明**：在系统级顺序图（SYS-SEQ）基础上展开后端内部组件：URL 路由、视图、序列化器、权限、模型、邮件、媒体存储。不展开到具体方法名（方法级见 OBJ-SEQ）。

## UC01 用户注册（COMP-SEQ01）

```mermaid
sequenceDiagram
    actor U as 用户
    participant FE as 前端组件 Register.jsx
    participant URL as URL 路由
    participant CODE as 视图 SendVerificationCodeView
    participant VIEW as 视图 UserViewSet
    participant SER as 序列化器 UserSerializer
    participant MODEL as 模型层 User / EmailVerificationCode
    participant DB as MySQL
    participant MAIL as 邮件组件

    U->>FE: 填写邮箱，点击获取验证码
    FE->>URL: POST /api/auth/send-code/
    URL->>CODE: 转发
    CODE->>MODEL: 校验邮箱、生成 6 位码
    MODEL->>DB: 写入 email_verification_codes
    CODE->>MAIL: send_mail 验证码
    CODE-->>FE: 200
    U->>FE: 填写用户名/密码/验证码并提交
    FE->>URL: POST /api/users/
    URL->>VIEW: create
    VIEW->>SER: 校验字段与验证码
    SER->>MODEL: 密码哈希并创建用户，核销验证码
    MODEL->>DB: INSERT users
    VIEW-->>FE: 201
    FE-->>U: 跳转登录
    Note over U,MAIL: 备选：验证码错误/过期/用户名重复 → 400
```

## UC06 教师编辑 / 删除课程（COMP-SEQ06）

```mermaid
sequenceDiagram
    actor T as 教师
    participant FE as 前端组件 CourseList
    participant URL as URL 路由
    participant VIEW as 视图 CourseViewSet
    participant PERM as 权限组件 IsCourseTeacherOrReadOnly
    participant MODEL as 模型层 Course
    participant DB as MySQL

    T->>FE: 编辑或删除
    FE->>URL: PATCH/DELETE /api/courses/{id}/
    URL->>VIEW: update / destroy
    VIEW->>PERM: has_object_permission（授课教师或管理员）
    alt 无权限
        PERM-->>VIEW: 拒绝
        VIEW-->>FE: 403/404
    else 有权限
        VIEW->>MODEL: 更新或删除（级联作业与提交）
        MODEL->>DB: UPDATE/DELETE
        VIEW-->>FE: 200/204
    end
```

## UC14 管理员后台管理（COMP-SEQ14）

```mermaid
sequenceDiagram
    actor A as 管理员
    participant ADM as Django Admin 组件
    participant AUTH as 认证组件
    participant REG as Admin 注册（User/Course/Assignment/Submission）
    participant MODEL as 模型层 ORM
    participant DB as MySQL

    A->>ADM: 登录 /admin/
    ADM->>AUTH: 校验 is_staff
    AUTH->>DB: 查询管理员
    A->>ADM: 增删改查用户/课程/作业/提交
    ADM->>REG: 调用已注册 ModelAdmin
    REG->>MODEL: ORM
    MODEL->>DB: SQL
    ADM-->>A: 列表/表单更新
```
