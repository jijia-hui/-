## 零、如何进入平台（演示前必看）

### 最快路径（推荐，Docker）

**前置：** 电脑已安装并启动 [Docker Desktop](https://www.docker.com/products/docker-desktop/)（托盘图标为 Running）。

在 **PowerShell** 中执行（路径按你本机仓库位置改）：

```powershell
cd "C:\Users\ASUS\Downloads\--main (2)\--main8.27"

# 第一次或很久没开：复制环境文件（可选，不复制也能启动）
copy .env.example .env

# 启动（首次会 build，约 3～8 分钟）
docker compose up -d --build

# 看三个服务是否 healthy
docker compose ps

# 导入演示账号和示例课程（幂等，可重复执行）
docker compose exec backend python manage.py seed_data
```

**浏览器打开：**

| 用途 | 地址 |
|------|------|
| **平台首页（登录后看课程）** | http://localhost:8080 |
| 登录页 | http://localhost:8080/login |
| 注册页 | http://localhost:8080/register |
| 健康检查（给助教看后端活着） | http://localhost:8080/api/health/ |
| Django 管理后台（UC14） | http://localhost:8080/admin/ |

**演示账号（执行 `seed_data` 后可用）：**

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 教师 | `demo_teacher` | `Demo@1234` |
| 学生 | `demo_student` | `Demo@1234` |

登录后会自动进入 **课程列表** `/courses`。

### 演示走法（2 分钟版）

1. 打开 http://localhost:8080/login → 用 `demo_student` 登录  
2. 点一门课 → 选课 → 进入作业列表 → 打开某个作业  
3. 退出 → 换 `demo_teacher` 登录 → 看学生提交、评分  

若要演示 **注册 + 验证码**：打开 http://localhost:8080/register  
- `.env` 里配了 QQ 邮箱 → 验证码发到邮箱  
- **没配邮箱** → 验证码在后端日志里：`docker compose logs backend`（搜 6 位数字）

### 打不开时排查

```powershell
docker compose ps          # 三个都应是 healthy
docker compose logs backend --tail 50
docker compose logs frontend --tail 20
```

| 现象 | 处理 |
|------|------|
| 8080 被占用 | 改 `.env` 里 `WEB_PORT=8081`，再 `docker compose up -d`，访问 http://localhost:8081 |
| 页面一直转圈 | 等 backend 变 healthy（首次 migrate 要 1～2 分钟） |
| 登录后没课程 | 再跑一次 `seed_data` |
| Docker 未启动 | 先开 Docker Desktop，等 Running 后再 `docker compose up` |

### 演示结束 / 下次再开

```powershell
docker compose down        # 停止，数据库数据保留
docker compose up -d       # 下次直接起，一般不用 --build
```

### 不用 Docker 的备选（仅开发调试）

需要本机 MySQL 8 + Python 3.12 + Node 20，步骤见仓库根目录 `README.md`「本地开发」一节。  
**中期演示建议只用 Docker**，一条命令全员环境一致。
