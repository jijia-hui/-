# 看板与统计页面截图目录

按任务书要求，**每天保存一次看板截图和统计页面截图**，文件名带日期。

## 截图方法

1. 双击打开 `05_management/统计页面.html`
2. 浏览器可按 **F11** 全屏
3. 用 **Win + Shift + S** 分别截：
   - 五列看板区 → `看板_YYYYMMDD.png`
   - 顶部指标 + 评分项 → `统计_YYYYMMDD.png`
4. 保存到本目录

GitHub Projects 截图：按 `统计页面.html` 底部「把组长 GitHub 看板改成这个样子」改完后再截一张，文件名可用 `看板_YYYYMMDD_github.png`。

## 文件命名

| 文件名 | 内容 |
|---|---|
| `看板_YYYYMMDD.png` | HTML 五列看板，或 GitHub Projects 五列 |
| `统计_YYYYMMDD.png` | HTML 顶部指标与评分项 |
